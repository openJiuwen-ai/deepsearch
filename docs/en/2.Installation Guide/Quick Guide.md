This document describes how to install **DeepSearch**.

![DeepSearch installation flow](../images/installation_guide/deepsearch安装流程.png)


To help you get started quickly, the community provides two installation paths:

* **[DeepSearch SDK](./DeepSearch_SDK/README.md)**: Deploy only the DeepSearch SDK backend—no web UI. Use via CLI or API. Suited to developers extending DeepSearch or contributing.
* **[DeepSearch Full Edition](./DeepSearch%20Full%20Edition/README.md)**: Deploy both the DeepSearch SDK backend and the web UI. Use the DeepSearch agent in the browser. Suited to users who want a UI-first experience.
