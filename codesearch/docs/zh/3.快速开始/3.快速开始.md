# 快速开始

## CLI

### 1. 索引一个本地仓库

```sh
python main.py index --repo /path/to/your/repo --collection my_repo
```

常用参数：`--max-files N`（小样试点）、`--no-trigram`（省 ~85% 存储，代价：
精确子串检索失效）、`--revision <tag>`（版本标签）、`--reset`（重建 collection）、
`--milvus-host/--milvus-port`（非默认 Milvus 实例）。

预期输出：`Indexed 132 files (132 new, 0 reused), 890 chunks inserted.`
重复索引未变更仓库显示 `(0 new, 132 reused)` —— 增量去重生效。

### 2. 检索

```sh
export OPENAI_API_KEY="sk-or-v1-..."
export OPENAI_BASE_URL="https://openrouter.ai/api/v1"   # 默认即可，可省略
python main.py search --collection my_repo --query "TypeError when calling foo() with empty list" --top-k 10
```

预期输出：

```
Termination: submitted | turns=6 | cost=$0.1234
 1. src/utils/foo.py (L42-L57)
 2. src/core/handler.py (L103-L120)
```

`Termination` 取值：`submitted`（智能体主动提交）/ `stagnated`（连续多轮零收获提前停）/
`max_turns`（轮次耗尽降级返回）/ `index_not_ready`（该 collection/revision 无索引）。

## Python API

```python
import asyncio
from openjiuwen_codesearch import CodeSearchConfig, CodeSearchRetriever

async def main():
    config = CodeSearchConfig.from_env()
    retriever = CodeSearchRetriever(config, collection_name="my_repo")
    await retriever.index_repository("/path/to/repo", revision="abc123")
    result = await retriever.search("issue 描述...", revision="abc123", top_k=20)
    for hit in result.hits:
        print(hit.file_path, hit.start_line, hit.end_line)

asyncio.run(main())
```

自定义模型 / 本地端点（任意 OpenAI 兼容 API）：

```python
from openjiuwen_codesearch.config.llm import LLMConfig, LLMSuite

config = CodeSearchConfig(
    llm=LLMSuite(
        main=LLMConfig(model_name="qwen3:32b", api_base="http://localhost:11434/v1"),
        filter=LLMConfig(model_name="qwen3:8b", api_base="http://localhost:11434/v1", max_tokens=2048),
    )
)
```

## Retropus 引擎（可选）

KG + BM25 检索，不依赖 Milvus。安装 `[retropus]` 后设置
`config.agent.engine = "retropus"`（或 ContextBench `--engine retropus`）。
循环/索引参数在 `CodeSearchConfig.retropus`，由 `MAX_*` / `IMP_*` / `RETRIEVER`
等环境变量加载（见仓库 [`.env.example`](../../../.env.example) 与
[retropus-agent.md](../../feature/framework/retropus-agent.md)）。

```python
config = CodeSearchConfig.from_env()
config.agent.engine = "retropus"
retriever = CodeSearchRetriever(config, collection_name="unused")
await retriever.index_repository("/path/to/repo")  # 进程内 KG，无 Milvus
result = await retriever.search("issue 描述...", top_k=20)
```

## ContextBench 评测

```sh
git submodule update --init --recursive
# 将 contextbench_verified.parquet 放入 third_party/contextbench/data/ 后：
python -m benchmarks.contextbench.runner --num-instances 32
# Retropus（需 pip install '.[retropus,bench,llm]'）：
python -m benchmarks.contextbench.runner --engine retropus --num-instances 5
```

预测与评分输出在 `./results/`。
