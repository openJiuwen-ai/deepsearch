# 快速指引

本指南帮助你选择合适的 CodeSearch 安装方式。

> **说明**：本产品依赖同仓的 `openjiuwen-search-base`（目录 `base/`）与
> `openjiuwen-codesearch`（目录 `codesearch/`）。源码与 Docker 构建会同时带上
> base；whl 正式发布时会同时提供 **两个** wheel，需一并安装。

为帮助你快速上手，社区提供如下三种安装方式：

- [源码安装](./源码安装.md)：推荐给开发者、贡献者或需要改代码调试的用户；
  在本地以 editable 方式安装 `base` + `codesearch`。
- [Docker 安装](./Docker安装.md)：推荐给需要隔离环境、快速起服务的用户；
  自行根据 Dockerfile 构建镜像（镜像内已含 base）。
- [whl 安装](./whl安装.md)：推荐给生产环境；从正式发布地址下载
  `openjiuwen-search-base` 与 `openjiuwen-codesearch` 两个 wheel 后安装，
  **不依赖源码树**。

公共环境要求、环境变量、Milvus、**待索引仓库（本地路径）** 与 HTTP 接口说明见
[安装指导总览](./README.md)。

> **注意**
>
> - **当前仅索引 Python（`.py`）文件**。非 Python 仓库索引结果为 0 个文件；
>   多语言可通过扩展 `Chunker` 支持，见[开发指南](../4.开发指南/README.md)。
> - 索引对象是**本机目录**；远程仓请先 `git clone`，再用本地路径索引。
>   检索时使用的是索引阶段起的 **collection 名**，不是仓库 URL。
> - **HTTP 服务不含鉴权**，且 `/api/v1/index` 读取服务端本地目录。必须配置
>   `CODESEARCH_INDEX_ROOTS` 白名单（未配置时索引接口返回 403，属预期行为），
>   并将服务部署在可信网络内或置于带访问控制的网关之后。
