# 源码安装

推荐给开发者、贡献者或需要代码定制的用户。需手动设置依赖，便于调试与修改。

## 一、环境准备

| 项 | 要求 |
|---|---|
| Python | >= 3.11 |
| Milvus | >= 2.5（推荐 2.6.x），索引与检索均需要 |
| LLM API Key | `OPENAI_API_KEY`（仅检索需要；`OPENAI_BASE_URL` 默认 OpenRouter） |

确认产品仓库布局（monorepo）：

```text
<repo_root>/
├── base/           # openjiuwen-search-base
└── codesearch/     # openjiuwen-codesearch（本包）
```

下文在 `codesearch/` 目录执行命令。公共环境变量与 Milvus 说明见
[安装指导总览](./README.md)。

> **待索引的代码仓**：索引接口只接受**本机已存在的目录路径**（不是 git URL）。
> 网上的仓库请先 `git clone` 到本地，再用该本地路径做 `--repo` /
> `repo_path`。详见[安装指导总览 · 待索引仓库](./README.md#待索引仓库本地路径)。

## 二、安装方法

使用 uv：

```sh
cd codesearch
uv venv .venv
uv pip install -e ../base -e '.[milvus,llm,server]'
```

使用 pip：

```sh
cd codesearch
python3 -m venv .venv
.venv/bin/pip install -e ../base -e '.[milvus,llm,server]'
```

> **说明**：必须先（或同时）安装同仓 `../base`。仅安装 codesearch 而不装 base
> 时，依赖解析会失败。可选 extras 说明见[安装指导总览](./README.md#可选依赖分组)。
> 仅在使用 `engine=retropus`（进程内 KG + BM25，不依赖 Milvus）时再加
> `retropus` 分组，例如 `'.[milvus,llm,server,retropus]'` 或 `'.[dev,llm,retropus]'`。

开发与单测可再加 `dev`：

```sh
uv pip install -e ../base -e '.[dev,milvus,llm,server]'
```

## 三、索引与检索（CLI）

将网上仓库拉到本地后索引（示例）：

```sh
# 1) 准备待检索代码仓（本地目录）
git clone git@gitcode.com:openJiuwen/agent-core.git /data/repos/agent-core
export TARGET_REPO=/data/repos/agent-core

# 2) 索引：--repo 是本地路径；--collection 是写入 Milvus 的集合名（自定）
export OPENAI_API_KEY="your-key"
export OPENAI_BASE_URL="https://openrouter.ai/api/v1"   # default; can omit
export MILVUS_HOST=localhost MILVUS_PORT=19530
codesearch index --repo "$TARGET_REPO" --collection agent_core --revision local --reset

# 3) 检索：只需要 collection 名（对应上面索引时起的名字），不再传仓库路径
codesearch search --collection agent_core --revision local \
  --query "TypeError when calling foo() with empty list" --top-k 20
```

## 四、启动 HTTP 服务

```sh
export CODESEARCH_INDEX_ROOTS="/data/repos"   # 须覆盖 $TARGET_REPO 的父目录
codesearch-server
# 等价：python start_backend.py
```

```sh
curl -sf http://127.0.0.1:8100/api/health

# 通过 HTTP 索引（repo_path 仍是服务端本地绝对路径）
curl -sS -X POST http://127.0.0.1:8100/api/v1/index \
  -H 'Content-Type: application/json' \
  -d "{\"repo_path\":\"$TARGET_REPO\",\"collection\":\"agent_core\",\"revision\":\"local\",\"reset\":false}"

# 检索同样只用 collection 名
curl -sS -X POST http://127.0.0.1:8100/api/v1/search \
  -H 'Content-Type: application/json' \
  -d '{"query":"TypeError when calling foo() with empty list","collection":"agent_core","revision":"local","top_k":20}'
```

更多 API 说明见 [快速上手](../3.快速上手/3.快速上手.md)。

## 五、常见问题

**与其他 openJiuwen 产品装在同一虚拟环境？**  
若锁定的框架版本不同则不能。请使用独立 venv 或容器；向量库层面可共存
（`cs_` 命名空间）。

**`uv` 报预发布版本错误？**  
源码树内 `[tool.uv] prerelease = "allow"` 已放行；若仍失败，加
`--prerelease=allow` 或改用 pip。更多见 [FAQ](../5.FAQ/README.md)。
