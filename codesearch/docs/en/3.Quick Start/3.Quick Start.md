# Quick Start

> **Note**
>
> - Indexing currently covers Python (`.py`) files only.
> - `--repo` / `repo_path` must be a **local directory**; clone remotes first.
> - `--collection` is a Milvus name you choose; search uses that name only.

## Command line

### 1. Index a repository

Prepare a local checkout if the code lives online:

```sh
git clone <git-url> /path/to/your/repo
```

```sh
codesearch index --repo /path/to/your/repo --collection my_repo
```

```
Indexed 132 files (132 new, 0 reused), 890 chunks inserted.
```

Re-indexing an unchanged repository shows `(0 new, 132 reused)` — incremental
deduplication at work.

| Option | Description |
|---|---|
| `--collection` | Collection name (a product prefix and schema version are added automatically) |
| `--revision` | Version label, any string; one collection can hold many revisions |
| `--max-files N` | Index only the first N files — useful for a small pilot run |
| `--no-trigram` | Skip the trigram field to cut storage significantly, at the cost of exact-substring search |
| `--reset` | Rebuild the collection (drops existing data) |
| `--milvus-host` / `--milvus-port` | Target a non-default Milvus instance |

### 2. Search

```sh
export OPENROUTER_API_KEY="your-key"
codesearch search --collection my_repo --query "TypeError when calling foo() with empty list" --top-k 10
```

For long problem statements, pass a file:

```sh
codesearch search --collection my_repo --query-file issue.txt --top-k 20
```

```
Termination: submitted | turns=6 | tokens=48213in/1876out
 1. src/utils/foo.py (L42-L57)
 2. src/core/handler.py (L103-L120)
```

Termination values are explained in the [FAQ](../5.FAQ/README.md).

## Python API

```python
import asyncio
from openjiuwen_codesearch import CodeSearchConfig, CodeSearchRetriever

async def main():
    config = CodeSearchConfig.from_env()
    async with CodeSearchRetriever(config, collection_name="my_repo") as retriever:
        report = await retriever.index_repository("/path/to/repo", revision="v1")
        print(report)

        result = await retriever.search("problem statement...", revision="v1", top_k=20)
        print(result.termination, result.total_input_tokens, result.total_output_tokens)
        for hit in result.hits:
            print(f"{hit.file_path} L{hit.start_line}-L{hit.end_line}")

asyncio.run(main())
```

### Custom models

The decision model drives retrieval; the filter model extracts relevant lines.
Both accept any OpenAI-compatible endpoint:

```python
from openjiuwen_codesearch.config.llm import LLMConfig, LLMSuite

config = CodeSearchConfig(
    llm=LLMSuite(
        main=LLMConfig(model_name="qwen3:32b", api_base="http://localhost:11434/v1"),
        filter=LLMConfig(model_name="qwen3:8b", api_base="http://localhost:11434/v1",
                         max_tokens=2048),
    )
)
```

### Tuning retrieval

```python
config.agent.max_turns = 30            # deeper search
config.agent.stagnation_rounds = 5     # stop later when no new findings
config.agent.retrieve_topk = 10        # fewer but more precise results
```
